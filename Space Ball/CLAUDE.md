# Space Ball — гайд для Claude / нової сесії

Android-гра на **libGDX + Box2D** (Kotlin). Гравець керує м'ячем чотирма кнопками
(стрибок, високий стрибок, вліво, вправо), стрибає по платформах угору до **варп-воріт**,
збирає зірки (рейтинг 0–3 на рівень, валюта магазину), уникає шипів, лазерів, чорних дір,
астероїдів. 60 рівнів на 4 планетах + щоденний рівень. Монетизація: AdMob (банер,
interstitial, rewarded), TikTok SDK для атрибуції реклами.

Детальні документи — у `docs/`:
- `docs/ARCHITECTURE.md` — структура коду, потоки, життєвий цикл екранів і тіл Box2D.
- `docs/GAMEPLAY.md` — правила, фізика з числами, планети/механіки, генератор рівнів, туторіал.
- `docs/TESTING.md` — як збирати, ставити на телефон, ганяти скриптовані тести, знімати скриншоти.
- `docs/MONETIZATION.md` — реклама, магазин, щоденний рівень, що зробити перед релізом.

## Команди

```bash
sh ./gradlew :app:compileDebugKotlin -q   # швидка перевірка компіляції (~20 с)
sh ./gradlew :app:assembleDebug -q        # debug APK (тестові ad unit ID)
sh ./gradlew :app:assembleRelease -q      # release з R8 — перевіряти перед здачею
adb install -r -d app/build/outputs/apk/debug/app-debug.apk
```
`./gradlew` без `sh` не запускається (немає execute-біта). Gradle-кеш AAR-ів: `~/.gradle/caches`.

## Правила проєкту (важливо)

- **Усе, що торкається AdMob, — лише на main-потоці.** Ігровий код виконується на GL-потоці
  libGDX; `MainActivity.showInterstitial/showRewarded` самі переходять на UI-потік, а їхні
  колбеки треба загортати в `runGDX { }` перед роботою зі сценою.
- **Debug-збірка використовує тестові ad unit ID** (`app/src/debug/res/values/strings_ads.xml`),
  release — справжні з `main/res/values/strings.xml`. Ніколи не клікати справжню рекламу під
  час розробки. `APPLICATION_ID` у маніфесті — справжній (працює і з тестовими unit ID).
- **Ключі TikTok — у `gradle.properties`** (`tiktok.app.id`, `tiktok.app.secret`), Gradle кладе
  їх у `BuildConfig`. Власник свідомо тримає їх у git (репозиторій публічний, пріоритет —
  відновлення проєкту з git). Не хардкодити в Kotlin. `local.properties` може їх перекрити.
  Без ключів debug збирається (SDK пропускається), release — падає з помилкою.
- Актори, що малюють себе ShapeDrawer-ом, при знищенні тіла мають бути `remove()`-нуті
  (зроблено в `AbstractBody.destroy`), інакше лишаються «привиди».
- Шейдерні квади малюються з білої текстури **4×4**, не 1×1: libGDX зсуває UV 1×1-регіону
  до центру пікселя (0.25..0.75) і шейдер бачить пів поля.
- Коментарі в коді — українською, як у решті проєкту. Ігрові рядки UI — англійською, великими.
- Шрифт `FontParameter().ui(size)` дає обводку+тінь — використовувати для всього тексту
  поверх фонів (фони дуже строкаті).

## Координати

Віртуальний екран **1080×1920** (FitViewport), Box2D-світ 6.75×12 м (`METER_UI = 160 px/м`).
Y вгору. На телефоні 1080×2400 гра летербоксована: `screen_y = 240 + (1920 − game_y)`.
Кнопки керування (game px): UP (139..295, 43..208), UPUP (321..477), LEFT (669..825), RIGHT (851..1007).

## Стан робіт (вересень 2026)

Зроблено й перевірено на пристрої: планети/механіки, ворота+рейтинг, подвійний стрибок,
гальмування на землі, магазин скінів (4 нові м'ячі `ballList` + відтінки), rewarded «Continue»
і «Free stars», щоденний рівень, туторіал на рівнях 1–2, шейдерні неонові кнопки/панелі
(`UiShader`/`NeonPanel`), частинки/слід/трясіння, процедурні звуки (`scratchpad/synth.py`
не в репо — 15 WAV у `assets/sound`).

Відкриття рівнів: вікно з 3 не пройдених рівнів у планеті, нова планета після 10/15, «SKIP LEVEL
(AD)» після 2 поразок (`LevelUtil`, див. `docs/GAMEPLAY.md`). Іконка — варіант C Horizon
(`tools/install_icon.py`), іконка для Play Console — `store/play_icon_512.png`.

Маркетинг: `store/` — скріншоти для Play Console, `store/video/` — ролики TikTok 9:16,
`store/icon_variants/` — варіанти іконки; скрипти в `tools/` (Pillow + imageio-ffmpeg у venv),
режим зйомки `--ez shots true` — див. `docs/TESTING.md`.

Не зроблено / ідеї: справжні спрайти для платформ, воріт, порталів, дір, астероїдів
(зараз ShapeDrawer/шейдер); UMP-згода для ЄС; більше скінів; нескінченний режим; локалізація.
